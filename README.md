## 📌 About The Project

This project uses **Machine Learning Regression Models** to predict house prices.

Different models are trained, tested, and compared to find the **best-performing model**.

```text

   ↓
🧹 Data Preparation
   ↓

   ↓

   ↓
🤖 Model Training
   ↓
📊 Model Evaluation
   ↓
🏆 Best Model
```
